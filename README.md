# 온결 — 나의 흐름을 읽는 사주

국내 출생자의 양력 생년월일시를 바탕으로 원국을 계산하고, 전통 명리의 상징을 생활 속 질문으로 읽는 정적 웹사이트입니다.

## 기능

- 1948년 이후 한국 표준시·서머타임, 경도 및 선택적 균시차 보정
- 절기 기반 연·월주, 일주 변경 및 대운 환산 방식 선택
- 십이신살, 귀문·백호·천을귀인과 원국·대운·세운·월운 관계
- 지장간·월지 가중 오행, 신강약 참고 지표, 일반격 및 보완 기운 후보
- 특징 태그에 따른 생활 해석, 20장 상세 리포트, 두 원국 비교, 결과 카드 저장

출생 정보는 브라우저에서 처리하며 별도 서버로 보내거나 저장하지 않습니다. Google Fonts를 불러오기 위한 외부 네트워크 요청은 발생할 수 있습니다.

## 실행

`dist/index.html`을 브라우저에서 열면 됩니다. 별도 빌드나 설치가 필요하지 않습니다.

## 검증

Node.js 22 이상에서 `npm test`를 실행합니다. 외부 패키지는 필요하지 않습니다.

브라우저 검사 파일 `verify-browser.cjs`는 개발 환경의 Playwright 경로를 사용하는 별도 확인 도구이며 기본 검사에는 포함하지 않습니다.

## GitHub Pages 배포

GitHub 저장소의 Settings → Pages → Source를 **GitHub Actions**로 설정합니다. `main` 브랜치에 올리면 검사 후 `dist/`가 자동 배포됩니다. 수동 배포는 Actions의 Deploy GitHub Pages 워크플로에서 실행할 수 있습니다.

## 계산의 범위

가중 오행과 신강약 숫자는 공개된 서비스 참고 모델이며 공인된 진단·예측 점수가 아닙니다. 격국·용신은 후보 수준으로 제시하며, 합화·종격·조후·격국 성패를 종합적으로 확정하지 않습니다. 한국 음력 입력은 지원하지 않습니다.

세부 규칙과 근거는 [CALCULATION.md](CALCULATION.md)를 참고하세요. 서비스는 오락·전통문화·자기 성찰을 위한 참고 자료입니다.

## 외부 라이브러리

`dist/vendor/lunar.js`는 [6tail/lunar-javascript](https://github.com/6tail/lunar-javascript)입니다. 해당 MIT 라이선스는 `dist/vendor/LICENSE`에 포함되어 있습니다. 프로젝트 자체에는 별도의 오픈소스 라이선스를 지정하지 않았습니다.
